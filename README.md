# Brown Memorial Skate Park

A responsive, interactive landing page presenting the skate park concept for Brown Memorial in Chicago's Chatham neighborhood.

The page uses the supplied concept drawing as its central visual. Visitors can explore the labeled skate features, accessible entry, gathering areas, and stormwater landscape through clickable markers and supporting sections.

## Preview locally

Open `index.html` in a browser, or serve this directory with any static web server.

## Format the source

```sh
npm install
npm run format
npm run format:check
```

Prettier is pinned as a development dependency so the project uses the same formatter version consistently.

## Design note

This is a concept presentation of the supplied drawing. It is not a construction document, and project details remain subject to design and community review.
